## 🛠 Tech Stack

This project is built from the ground up without heavy frontend frameworks to ensure maximum performance and granular control over the design:

* **HTML5**: semantic, accessible structure
* **Vanilla CSS3**: Custom design system, CSS variables, glassmorphism UI, typography, and responsive media queries
* **Vanilla JavaScript**: Smooth scrolling, dynamic counters, and intersection observer animations
* **Design Approach**: Premium Dark-Mode SaaS aesthetic, responsive layouts, subtle gradient glows, and engaging micro-interactions.

## 💻 How to Run Locally

You can run this project locally with zero dependencies.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd portfolio
   ```
2. **Run it:**
   - **Option 1**: Simply double-click the `index.html` file to open it in your default web browser.
   - **Option 2** (Recommended): Serve the directory using a local web server like VS Code's "Live Server" extension, or via Python:
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.

## 🌍 Deployment

This website is designed to be easily deployed using **GitHub Pages**. 

**Steps to Deploy:**
1. Push your code to a GitHub repository.
2. Navigate to your repository's **Settings** > **Pages**.
3. Under "Source", select the `main` branch and `/root` directory as your publishing source.
4. Click **Save**. Your site will be live at `https://yourusername.github.io/portfolio` in a few minutes!
